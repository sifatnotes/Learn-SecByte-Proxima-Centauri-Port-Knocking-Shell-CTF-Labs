# Learn SecByte Proxima Centauri, Port Knocking & Shell CTF Labs

A focused collection of **cybersecurity labs, CTF labs, hands-on cybersecurity labs, ethical hacking labs, and penetration testing labs** from Learn SecByte.

This collection centers on the Proxima Centauri and Centauri-themed exercises, with topics including reconnaissance, credential discovery, Linux capabilities, Perl, port hunting, backup trails, port knocking, Socat, browser-based shell scenarios, and shell stability.

These labs are suitable for cybersecurity students, CTF players, pentesters, SOC analysts, and security learners practicing in authorized environments.

## How to Use the Labs

1. Select a lab from the collection.
2. Read the provided lab instructions carefully.
3. Work only within the authorized CTF environment.
4. Identify the objective before beginning enumeration.
5. Record discovered ports, services, credentials, capabilities, and other relevant findings.
6. Document the reasoning behind each step.
7. Review the security concept after completing the challenge.

Skills represented across this collection include:

- Cybersecurity reconnaissance
- Network enumeration

- Linux capabilities
- Privilege escalation
- Port knocking
- Shell stabilization
